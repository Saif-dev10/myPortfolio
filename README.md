## Getting Started

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd my-portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application at:

```text
http://localhost:3000
```

## Environment Variables

If the project requires environment variables, create a `.env.local` file in the root directory.

Example:

```env
NEXT_PUBLIC_EXAMPLE_KEY=your_value
```

Do not commit private keys, passwords, tokens, or other credentials to the repository.
